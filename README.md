# 拼多多订单导出工具 (pdd_list_export)

自动抓取拼多多网页版「我的订单」，导出为 Excel 表格。**登录态复用你本机 Chrome，无需重新扫码**，数据全程在本地处理，不经过任何第三方。

## 功能特性

- ✅ 复用本机 Chrome 登录态，首次复制一次后免重复登录
- ✅ 自动滚动加载全部订单（含历史订单）
- ✅ 按日期过滤（默认 2026-06-01 至今，可改）
- ✅ 导出字段：下单时间、订单号、商品名称、规格、单价、数量、订单金额、实付金额、订单状态、店铺名、快递单号
- ✅ 金额自动由「分」转为「元」
- ✅ 支持 macOS / Linux / Windows（自动探测 Chrome 用户数据目录）

## 环境要求

- Python 3.8+
- 本机已安装 **Google Chrome**（或 Chromium / Edge）
- 已在该浏览器中登录过拼多多

## 安装

```bash
pip install playwright openpyxl

# 若使用 channel="chrome"（复用本机 Chrome），通常无需额外下载浏览器内核
# 如遇浏览器启动失败，可执行：
# python -m playwright install chromium
```

## 使用方法

### 1. 修改起始日期（可选）

编辑 `pdd_orders.py` 顶部：

```python
START_DATE = datetime(2026, 6, 1)   # 改成你需要的最早日期
```

### 2. 运行脚本

```bash
python3 pdd_orders.py
```

运行流程：

1. **首次运行**：脚本会复制本机 Chrome 登录态到 `./pdd_profile`（约几十秒）
2. 弹出 Chrome 窗口，打开拼多多订单页
3. 若未登录，在弹出的浏览器里扫码/密码登录（自动化标记已去除，不会触发「发送失败」风控）
4. 登录完成后，回到终端**按回车**
5. 脚本自动滚动加载全部订单，抓取完成后生成 Excel

### 3. 查看结果

脚本会在当前目录生成：

```
拼多多订单_2026-06至今.xlsx
```

终端会输出订单条数和实付合计金额，例如：

```
✅ 完成！共 174 条订单（2026-06 至今），实付合计约 ¥xxx.xx
```

## 输出字段说明

| 字段 | 说明 |
|---|---|
| 下单时间 | 精确到秒 |

## 常见问题

**Q：提示「未找到本机 Chrome 用户数据目录」？**
A：在脚本顶部手动设置 `CHROME_USER_DATA` 为你的 Chrome 用户数据路径（macOS 默认 `~/Library/Application Support/Google/Chrome`）。

**Q：抓到的订单数比预期少？**
A：脚本按「滚动到底 + 连续 15 轮无新订单」判定结束。如果订单量特别大，可以调大脚本中 `max_rounds`（滚动轮次上限）或 `idle >= 15` 的阈值。

**Q：登录态保存在哪？会不会泄露？**
A：登录态复制到本地的 `./pdd_profile` 目录（已在 `.gitignore` 中排除，不会上传到 GitHub）。删除该目录即可清除登录态。

**Q：会不会触发拼多多风控？**
A：脚本已去除 `navigator.webdriver` 自动化标记，并复用真实 Chrome 登录态，属于正常浏览器行为，风险较低。但仍建议不要高频运行。
